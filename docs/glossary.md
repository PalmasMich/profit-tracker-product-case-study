# Glossario

| Termine | Significato nel case study |
| --- | --- |
| Matched betting | processo basato sulla copertura di esiti opposti, non sulla previsione dell'evento |
| Operazione | contenitore funzionale che aggrega una o più componenti e il relativo risultato |
| Puntata | componente associata a un determinato esito |
| Bancata | componente che copre l'esito opposto tramite exchange |
| Punta-punta | copertura realizzata tramite puntate su esiti complementari |
| Promozione | iniziativa con condizioni, stato, scadenza e attività collegate |
| Operatore | bookmaker, exchange o altro soggetto censito nell'anagrafica |
| Conto operatore | account effettivamente utilizzato dall'utente |
| Wallet | strumento di pagamento o conto esterno |
| Movimento | deposito, prelievo, trasferimento o rettifica |
| Riconciliazione | verifica della coerenza tra dati registrati e saldi osservati |
| Competenza | periodo al quale viene attribuito il risultato |
| Multipla progressiva | flusso composto da più eventi e decisioni successive |
